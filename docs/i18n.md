# InviteMe Vietnamese and English interface

InviteMe uses `i18next` with `react-i18next` for the browser UI. Vietnamese (`vi`) is the default and fallback language; English (`en`) is the second supported locale. Translation resources are static files under `src/i18n/locales/{vi,en}` and are bundled locally, so switching languages does not call an external translation service or backend API.

## Persistence and rendering

The language selector immediately changes the current React interface and writes the selection to both `localStorage` (`inviteme.language`) and the `inviteme-language` cookie. The cookie lets the Next.js root layout render the selected `<html lang>` on refresh and prevents a server/client language flash. The preference is browser-level, so it remains after sign-out and sign-in on the same browser. There is no account-level language preference API in the current backend.

## Namespaces

The current namespaces are `common`, `navigation`, `settings`, `auth`, `dashboard`, `public`, `landing`, `screens`, `weddings`, `admin`, `guests`, `audit`, `gifts`, `cohost`, `invitations`, `thankYou`, `guestPlanning`, and `templateStudio`. Keep keys semantic and update both locale files together. `tests/i18n.test.ts` checks that every locale has the same key structure.

Template Studio editor controls and the Wedding Website editor use their own translation groups. Invitation artwork, sample wedding copy, names and dates stored in the design document remain content and are not rewritten when the UI locale changes.

Wedding titles, names, stories, guest details, saved invitation copy, template content, and other persisted user-authored content remain unchanged when the interface language changes. Only application-owned labels and messages are localized. Display-only dates and numbers use `Intl` with `vi-VN` or `en-US`; stored timestamps and API payloads are not changed.

## Existing typography and brand tokens

The interface font declarations in `src/app/globals.css` remain unchanged: body text uses `--font-sans: "Be Vietnam Pro", sans-serif`; display text uses `--font-display: "Noto Serif", Georgia, serif`. Both Be Vietnam Pro and Noto Serif include Vietnamese font assets. Wedding template styles retain their own current declarations, including EB Garamond where already used. No font was added or replaced for i18n.

The existing pastel brand tokens also remain unchanged: `--primary: #efa3b3`, `--brand-soft: #f8c9d2`, and `--petal: #fdecef`.

The on-device seating preview in guest import localizes its controls, table and RSVP labels, status messages, and number display. Guest names, group names, and notes remain as entered.
